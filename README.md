# 🧠 OPEN SOURCE BUDDY  
### YOUR AI POWERED CONTRIBUTION COMPANION 🚀 + 🤖  

Tired of endlessly scrolling GitHub to find good open-source projects?  
**Open Source Buddy** is your one-click assistant to discover 🔥 active, beginner-friendly open-source projects — all filtered smartly by AI.

---

## 🌟 What it does  

Just give it your:  

✅ Topic or Tech Stack (e.g., `AI`, `Python`, `Web Dev`, etc.)  
✅ Optional filters (like stars, issues, help wanted)  

And it magically finds:  

🔍 High-quality GitHub repos  
💬 Help-wanted issues  
⚡ Projects with high stars & activity  
📌 Clean formatted results (in HTML or JSON)  

---

## 🧠 Powered By  

| Tech | Role |
|------|------|
| 🐍 Python | Backend |
| 🌐 Flask | Web framework |
| 🤖 LangChain | Intelligent response formatting |
| 🔐 GitHub API | Repo search |
| 📝 Markdown + HTML | Frontend rendering |
| 🌍 dotenv | Token + env mgmt |

# ⚙️ How to Run

1. **Clone the repo**
    ```bash
    git clone https://github.com/Harsimran-singh-7765/OpenSource-Buddy.git
    cd OpenSource-Buddy
    ```

2. **Install requirements**
    ```bash
    pip install -r requirements.txt
    ```

3. **Create a .env file and add:**
    ```env
    GITHUB_API_TOKEN="your_github_token_here"
    ```

4. **Run the app:**
    ```bash
    python app.py
    ```
